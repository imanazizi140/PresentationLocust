# LOCUS-T Graduating Intern Sharing

Vanilla HTML, CSS, and JavaScript browser presentation with six 16:9 slides.

## Open locally

Double-click `index.html`, or serve the folder with any static server. For example:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000>.

Use the left/right arrows or Space to navigate. The on-screen controls support previous/next navigation and fullscreen mode. Press Escape to leave fullscreen.

## Add real images

Place your personal and project files in `assets/`: `profile-photo.jpg`, `office-photo.jpg`, `mygpt-chatbot.png`, `openai-chatbot.png`, `chatwoot-dashboard.png`, `shuffle-website.png`, `strongest-project.png`, and `team-photo.jpg`. The cover uses `locus-t-logo.svg` and the supplied `digital-bee-logo.png`. Missing personal/project images render as labeled placeholders.
